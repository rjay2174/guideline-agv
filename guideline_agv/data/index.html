IR Line Sensor Diagnostics

With the AGV stopped, place the five sensors over a black guide line one at a time. Select the polarity that lights the correct sensor only when it sees black. The setting is saved to NVS.

Physical Speed Knob (GPIO3)

The physical 10 kOhm potentiometer controls speed without a phone. Turn to zero to stop wheel PWM. Automatic steering correction, bridge and recovery speeds scale with it.

Recognition thresholds

The threshold is maximum normalized RGB distance (0.025–0.300). Lower values reject more uncertain colors. Start with the defaults and adjust using the live match distance.
